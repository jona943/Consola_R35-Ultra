# Motor de Aceleracion por Memoria RAM y SIMD NEON (R35 Ultra)

Este directorio contiene la documentacion tecnica, diagramas de arquitectura y especificaciones del motor de aceleracion de software disenado para aliviar el cuello de botella de la GPU Mali-G31 mediante el aprovechamiento de los 500+ MB de memoria RAM LPDDR3 libre y las unidades vectoriales ARM NEON de 128 bits.
