# Carpeta de Arboles de Dispositivos (dtb_r36ultra/)

Este directorio contiene los arboles de dispositivos compilados (Device Tree Blobs - `.dtb`) y archivos de arranque `.ini` de referencia para consolas de la serie R35/R36 Ultra con procesador Rockchip RK3326.

---

## Indice de Archivos

| Archivo | Descripcion y Uso |
| :--- | :--- |
| **`rk3326-r36ultra-linux.dtb`** | Arbol de dispositivos para placa base R36/R35 Ultra con definicion de buses I2C, pines GPIO y direccionamiento del panel MIPI DSI. |
| **`rk3326-r36ultrax-linux.dtb`** | Variante de arbol de dispositivos para revisiones Ultra X. |
| **`boot.ini` / `boot_ultrax.ini`** | Archivos de configuracion del cargador de arranque con frecuencias de inicializacion y parametros de linea de comandos del kernel. |
